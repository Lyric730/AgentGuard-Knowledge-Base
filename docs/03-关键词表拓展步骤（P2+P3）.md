# 关键词表拓展步骤（P2+P3）

## 一、 AI + SEO 工具加持下的“极速 3 步 SOP”

```Plain Text
Step 1: 工具一键导出 (Ahrefs/Semrush) -> 批量拿到竞品 Top Keywords & Pages
Step 2: AI 极速清洗与聚类 (Prompt)    -> 几秒内完成 Intent 分类、词聚类与 URL 匹配
Step 3: 人工审阅与优先级定级          -> 确认 P0/P1/P2
```

### 极速 3 步具体怎么做？

1. **Step 1：工具一键导出（海量抓取）**

   - 打开 Ahrefs / Semrush 输入竞品域名（`lakera.ai`, `zenity.io` 等）导出 **Top Keywords** 和 **Top Pages** 报表（CSV）。
   - 打开 Site Explorer  搜 `MCP Security` / `AI Agent Security`  导出所有 **Matching Terms**。
2. **Step 2：AI 自动化聚类与映射（把数据投给 AI）**

   - 将导出的 CSV 数据喂给 AI，直接用 Prompt 处理：

   > - *“请帮我分析以下关键词数据：按照页面类型、URL、目标关键词、xxx 输出一个完整的SEO关键词表''*
3. **Step 3：人工审阅与优先级分配**

   - 人工检查 AI 的归类是否符合 AgentGuard 的业务实际，以及优先级是否合理
