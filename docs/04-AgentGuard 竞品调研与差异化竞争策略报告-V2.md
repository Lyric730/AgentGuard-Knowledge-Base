## 一、 核心结论：AgentGuard 的定位与锚点

**核心定位：AgentGuard is the CISO for Autonomous Agents.**

我们不只做一次性的代码扫描或简单的 Prompt 文本过滤，而是为开发者和企业安全团队提供**持续看见风险、验证风险、拦截危险动作并保留审计证据**的完整 AI CISO 能力。

需明确的**七大现状事实与业务分水岭**：

1. **直接竞品明确**：采购对比聚焦于 Lakera、HiddenLayer 等 6 家，避免陷入泛网络安全行业的红海竞争。
2. **SEO 追赶路径**：Lakera 领跑搜索流量（美国约 1.84 万/月），AgentGuard 早期切忌盲目堆砌无序页面。应严格遵循现有网站架构（IA）进行精细化路径收敛，优先打透四大核心功能页（/features/）与高意图的垂直方案页（如 /solutions/mcp-agent-security），配合术语库（/glossary）建立技术权威并为主站权重（PageRank）高效输血。
3. **售卖逻辑对齐**：竞品普遍遵循“**暴露风险 $\rightarrow$ 产品干预 $\rightarrow$ 提供信任证据**”的三段式叙事，我们的落地页必须严格执行此对应关系。
4. **核心差异化**：打破传统 B2B“先聊 Demo”的壁垒，以开发者侧的 Quickstart、开源生态（GitHub/CLI/API）为第一入口，构建**开发者自下而上驱动**的 AI CISO 防线。
5. **严控对外宣称的产品边界**：

   - **当前核心事实（可对外宣传的 7 大能力）**：Runtime Guard（运行时防护）、Deep Scan（深度扫描）、OpenClaw Patrol（工作区巡检）、Docs/API、GitHub 开源与 CLI、Integrations（集成环境）、Advisories（安全公告）。
   - **长远战略方向（暂不对外承诺）**：Discover（风险发现）、Red-Team（AI 红队）、Govern（合规治理），此三项作为产品愿景，暂不建立公开能力页，避免透支品牌信任。

### 核心数据推演与动作决策

- **市场国际化策略（P1 级别）**：直接竞品的全球流量普遍远超美国本土（如 Lakera 达 3 倍空隙）。这表明全球市场存在长尾流量，但**转化为实际营收的质量尚需验证**。AgentGuard 应在技术架构上预留国际化多语言扩展位。
- **关键词破局点（P2 级别）**：竞品的流量并非来自“AI 安全”等宏观泛词，而是全部绑定在**具体任务和新型风险**上（如 Lakera 靠 Gandalf 安全游戏，Noma 抓住了 MCP 协议爆发红利）。AgentGuard 必须放弃宽泛词，锁定“`具体 Agent / Host组件 + 具体风险 + 拦截/修复动作`”的三元组长尾词。
- **内容选题优先级（P3 级别）**：结合 Blog 的 5 大分类内容落地规范与 Security 目录进行立体渗透。我们不盲目追求品牌词与时政热点，严禁生产空洞的科普软文，内容生产需遵循以下优先级：  

  1. **第一优先级（P1）**：**Guides (How-to 深度指南)** 与 **Security (威胁/检测数据库)**。直接面向一线安全开发人员，针对具体漏洞（如 *“How to Prevent MCP Response Spoofing”*）输出防御方案，并将 `Runtime Guard` 作为一键自动防御方案嵌入，同时通过 `/threat-database` 沉淀技术背书。  
  2. **第二优先级（P2）**：**Glossary (术语库 Wiki)** 与 **Review (前沿攻防审查)**()。编写如 *“What is Agent Dependency Pollution?”* 等精简 Wiki 词条字典，利用高密度内链为主站核心功能页分发权重，并利用 Review 展示团队对新型 AI 攻击向量的深度理解。  
  3. **第三优先级（P3）**：**Compare (竞品对比)** 与 **Best (聚合推荐)**。直接拦截处于购买决策最后一公里的高意图买家（如 *“AgentGuard vs [竞品]: Features and Latency Comparison”* 及 *“Best Model Context Protocol (MCP) Security Tools in 2026”*。

## 五、 AgentGuard 差异化竞争与突围策略

面对市场乱局，AgentGuard 实行“开发者切入 + Factual 事实背书”的差异化战略。

### 改变转化路径：做“开发者触手可及”的 AI CISO

传统竞品高度依赖销售驱动的 “Book a Demo” 模式，门槛高、体验重。AgentGuard 核心 CTA（行动激励）直接指向 **Quickstart** 和 **CLI/API 试用**。让开发者在没有任何商务接触前，即可直接完成本地环境的风险扫描。

### 简化产品表达：“组件风险”与“动作风险”双重截击

告别竞品宽泛抽象的“AI 安全平台”话术，用极简的“两段式”直击产品核心：

- **Deep Scan**：解决静态风险。检查 Agent 准备安装和使用的组件是否存在后门、凭据泄漏或注入漏洞。
- **Runtime Guard**：解决动态风险。在 Agent 即将执行 shell 命令、文件读写、网络请求等核心动作前，实时判定是否合规并进行拦截。

### 克制收敛：以 7 项当前已证实的硬核能力构筑信任

我们杜绝任何未上线功能的虚假承诺，页面只陈列具有强证据链的七大事实：

- **Runtime Guard**：拦截高危 Shell 命令、文件恶意篡改、网络外溢和敏感数据泄漏。
- **Deep Scan**：扫描 Skill、Plugin、MCP Server、仓库及三方组件包。
- **OpenClaw Patrol**：针对 OpenClaw 工作区的专属安全巡检，监控可信文件的变动。
- **Docs/API**：提供开箱即用的配置说明与标准的运行时安全判定接口。
- **GitHub 生态**：开源核心逻辑，提供 CLI 工具，走 MIT 许可，降低开发者抵触情绪。
- **Integrations**：明文罗列已支持的 Agent 框架、IDE 插件与 Host 环境，不虚夸覆盖范围。
- **Advisories**：高标准维护带编号的公开安全公告，输出修复建议，打造行业权威感。
