# 执行要点：

## 📌 任务一：P0 核心页面 SEO 策划（首页、核心产品页等）

### 关键词与搜索意图映射（Keyword & Intent Mapping）

- 对齐《P2 关键词与内容规划》，为首页及各产品页分配主关键词（Primary KW）与次要关键词。
- 明确每个页面的核心搜索意图（如商业意图/交易意图），确保页面定位精准匹配 Target Audience。

### 页面信息架构搭建

- 梳理页面视觉与内容层级：H1 主标题（Hero Section）、H2 核心产品价值/功能点、H3 细分场景/技术优势。
- 规划用户信任背书模块（如案例、资质认证、客户 Logo）及底部转化区。

### 高转化 SEO 英文文案撰写（Drafting）

- 撰写符合 SEO 规范且具吸引力的英文 Pitch 文案，在 Heading 及核心段落自然植入目标关键词。
- 提炼产品 Feature/Benefit 差异化卖点，确保文案地道、专业。

### On-Page SEO 元素标定

- 为每个页面定制 Meta Title（<60 字符，含主词）与 Meta Description（<160 字符，含行动号召）。
- 标注重点图片的 Alt Text、页面内部链接跳转逻辑及锚文本（Anchor Text）。

### 转化组件与 CTA 规划

- 设计高转化率的 CTA 组件建议（如 Free Trial、Book a Demo 等入口）。
- 完成 SEO 策划稿汇编

---

## 📌 任务二：博客页面 SEO 模板策划（Blog 聚合页、分类页、详情页）

### 树状结构与高保真原型绘制

- 规划 Blog 架构： Blog 首页 $\rightarrow$ 分类/专题聚合页 $\rightarrow$ 文章详情页。
- 输出高保真原型图，定义各级页面的导航、面包屑（Breadcrumbs）、分类标签及布局逻辑。

### 详情页 SEO 与转化 UX 布局

- **阅读体验与留存：** 规划文章目录（Table of Contents）、预计阅读时间、作者/专家信息栏等组件。
- **转化路径（CTA）：** 针对不同搜索意图，设计文中内嵌式 CTA（In-article CTA）与侧边栏吸顶组件（Sticky Sidebar CTA）。
- **内链循环：** 设计“相关文章推荐（Related Posts）”和产品功能卡片，降低跳出率并引导流量流向 P0 核心页。

### Schema 结构化数据技术要求制定

- 撰写交付给开发团队的 Schema JSON-LD 技术规范文件，重点覆盖：

  - `BlogPosting` / `Article`（文章基础信息）
  - `BreadcrumbList`（面包屑层级）
  - `FAQPage`（若包含常见问题模块）

### 多内容形态模板与响应式规范

- 针对不同类型文章（如 How-to 指南、行业趋势分析、竞品对比）输出差异化的排版设计建议。
- 规范移动端（Mobile）与 PC 端的组件收纳及响应式适配展示逻辑。
