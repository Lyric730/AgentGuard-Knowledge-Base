# AgentGuard 01 关键词与搜索意图映射

这份表只回答一件事：28 个 P0 页面分别应该抢什么词。

- 每页只设一个主关键词；同一搜索需求下的近义词放到同页，不按“一词一页”拆分。
- 辅助关键词是同一页面需要自然覆盖的近义词和相关查询，不再拆成“来源辅助关键词”和“本轮建议次级关键词”两列。

## 需要客户确认

1. **AI CISO 是否是正式对外定位？** 如果不是，`/ai-ciso` 不应抢 `ai ciso`，相关词也不应继续扩写。
2. **Pricing 是否真实存在 free plan 和 enterprise pricing？** 如果尚未上线，应从本轮建议词中删除 `agentguard free plan` 或 `agentguard enterprise pricing`，避免页面承诺与实际产品不一致。
3. **执行范围：** 本轮只做美国英语市场，关键词保留英文原词。以后如扩展其他语言市场，需要另做本地化关键词验证，不能直接翻译本表。
4. **Review / Compare 的发布边界：** 当前保留语料中，合格 Review 和产品对产品 Compare 模板均为 0。可以先保留页面规划，但不能在证据不足时发布结论。
