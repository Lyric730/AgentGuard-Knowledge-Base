# 第三周任务执行清单（7.29-8.4）

<sheet sheet-id="25SyJf" token="TOQ7sao4Xh5C5LteQpfcm1Lin6X"></sheet>



### 核心执行步骤

**第一阶段：确认边界与竞品反向工程（至关重要）**

- **锁定代表性竞品**：在规划具体内容前，先明确我们要打透的市场边界。避免泛泛而谈，直接锚定几家最具代表性的核心竞品。
- **数据拆解与反推**：利用 Semrush 或 Ahrefs 等工具，导出这些核心竞品的 P0 页面和头部博客的流量与关键词布局数据。对他们的页面信息架构（H1/H2逻辑）进行反向工程，提炼出可复用的结构骨架。

**第二阶段：P1 任务（P0页面策划与原型）执行**

- **自动化内容生产**：将反向工程得出的页面骨架转化为具体的 Prompt，利用 AI Agent 规模化地生成英文文案初稿，以此突破纯人工撰写的效率瓶颈。
- **人工校验与UI适配**：对 AI 生成的文案进行专业度和本地化表达的精修。随后将文案直接填入高保真原型中，核对文本长度、断句是否影响整体的 UI/UX 视觉呈现。

**第三阶段：P2 任务（博客内容）执行**

- **大纲先行审批**：不要直接写全文。先基于长尾关键词产出8篇文章的 H2/H3 结构大纲，并提前规划好每篇文章指向 P0 页面的内部链接锚文本。
- **差异化润色**：在借助工具完成初稿后，人工介入的核心在于强化 AgentGuard 的“产品差异化”信息，确保内容能精准切中痛点，而非通篇泛泛的科普。

---

### 关键注意事项

- **执行顺序隔离**：务必坚持“先搭骨架，再填血肉”的原则。必须在竞品反向工程和关键词映射表完全确认无误后，再启动 AI 或人工的内容生成，避免大面积返工。
- **提示词（Prompt）标准化**：团队在调用 AI 工具生成页面 SEO Meta（Title, Description）和正文时，必须使用统一的提示词模板，确保字符数限制、关键词密度和品牌语调保持高度一致。
- **防过度 AI 化审查**：在最终交付前，需进行一次统一的交叉审阅，消除过于生硬或机械的机器生成痕迹，确保英文表达地道且具备说服力。
