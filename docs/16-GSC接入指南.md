# GSC接入指南

需要用新域名www.agentguard.one 新建Google Search Console项目，避免旧域名数据混淆，方便后续做分析。

访问https://search.google.com/search-console

### Step 1 添加资源



![图片展示的是Google Search Console添加资源界面。界面顶部有“Google Search Console”标题及搜索框，下方显示已添加的网址“https://lazyhairstyle.com/”，状态为“未验证”。底部有蓝色“添加资源”和“新选项”按钮。该图片对应文档中“Step 1添加资源”步骤，直观呈现了在Google Search Console中添加新资源的操作界面，帮助用户了解添加资源的具体位置和状态显示情况。](_assets/FqXYdRy4NoVxOHxxBPxc9p2xnic/003.png)

![这张图片展示了Google Search Console中选择资源类型的页面，对应GSC接入指南的Step 1添加资源环节。页面提供“网域”和“网址前缀”两类资源类型供选择，其中右侧的“网址前缀”类型已被选中，其输入框内预设内容为https://www.agentguard.one/，该域名正是接入指南要求新建项目所用的新域名，点击“继续”按钮可进入后续操作。左侧的“网域”类型适用于给定网域下所有子网域及对应网址，需进行DNS验证，两类类型各有对应的特性说明。](_assets/FqXYdRy4NoVxOHxxBPxc9p2xnic/001.png)



### Step 2 验证所有权

![图片展示的是Google Search Console中验证所有权的页面。上方显示网址https://www.agentguard.one/。推荐的验证方法为HTML文件，需下载文件“googleleaf55ff749f15595.html”，上传至指定网址，且需保持文件不被移除。下方还有其他验证方法，包括HTML标记、Google Analytics、Google跟踪代码管理器、域名提供商等，每种方法均有展开按钮。页面右下角有“移除资源”和“完成”按钮。该图片与文档中“Step 2验证所有权”步骤对应，指导用户进行验证操作。](_assets/FqXYdRy4NoVxOHxxBPxc9p2xnic/002.png)
